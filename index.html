WHY UTXO CONTROL

잔액만 보는 지갑에서,
사용할 코인을 고르는 도구로.

지갑 잔액은 여러 개의 ‘아직 쓰지 않은 코인 묶음’으로 이루어질 수 있습니다. 이 묶음을 UTXO라고 합니다.

UTXO Control은 전송에 사용할 묶음을 직접 고르고, 보내는 금액과 수수료를 확인하는 데 집중합니다. BTCMobick 사용자가 자신의 거래를 더 명확하게 이해하고 제어할 수 있도록 만들었습니다.

개념 설명용 예시

A SMALL GUIDE

처음이라면,
이 순서로 시작하세요.

개인키는 이 웹페이지에 입력하지 마세요.
지갑 열기와 전송은 설치한 앱 안에서만 진행합니다.

  1. 01

    지갑을 열어요

    본인이 관리하는 지갑의 WIF 개인키를 앱에서 입력하거나 QR로 읽습니다. 개인키는 외부에 공유하지 말고 원본을 안전하게 보관하세요.

  2. 02

    보낼 코인을 골라요

    잔액과 UTXO 목록을 확인하고 사용할 항목을 선택합니다. Legacy와 Native SegWit 주소의 잔액을 확인할 수 있습니다.

  3. 03

    주소·금액·수수료를 확인해요

    받는 주소를 입력하거나 QR로 읽고 전송 금액을 정합니다. 최종 확인 화면에서 주소, 선택한 코인, 금액과 수수료를 다시 확인하세요.

  4. 04

    인증하고 전송해요

    PIN 또는 설정한 생체인증으로 확인합니다. 거래는 기기에서 서명하며, 서명된 거래를 네트워크에 전송합니다. 전송 후 거래 번호(TXID)로 처리 상태를 확인하세요.

PRIVATE KEY · SESSION ONLY

개인키를 저장하는
기능은 없습니다.

입력한 개인키는 앱 실행 중 세션 메모리에서만 사용하며, 기기 저장소에 영구 저장하지 않습니다.

화면 잠금이나 홈 화면 이동만으로 세션이 종료되지는 않습니다. 앱 프로세스가 종료되면 개인키를 다시 입력해야 합니다.

개인키 원본은 사용자가 별도로 안전하게 보관해 주세요.

YOUR KEYS. YOUR RESPONSIBILITY.

직접 관리하는 만큼,
확인은 신중하게.

UTXO Control은 코인을 대신 보관하는 서비스가 아닙니다. 거래를 전송하기 전에 아래 내용을 꼭 확인하세요.

01

개인키를 보관해 주세요

현재 버전은 개인키를 세션 메모리에서 사용하며 영구 저장하지 않습니다. 앱은 개인키 분실 시 복구해 드릴 수 없습니다.

02

전송 전, 한 번 더 확인하세요

받는 주소와 네트워크, 금액과 수수료를 확인하세요. 전송된 거래는 취소가 어려우므로 처음에는 소액 테스트를 권합니다.

03

전송과 확정은 달라요

거래 번호가 생성되어도 블록 확정에는 시간이 걸릴 수 있습니다. 거래 조회 결과와 확인 수를 확인하세요.

GOOD TO KNOW

궁금한 점을 모았어요.

UTXO Control은 어떤 네트워크용인가요?

BTCMobick을 위한 도구입니다. 다른 네트워크의 코인을 지원한다고 가정하지 마세요. 주소 형태가 비슷해도 사용하려는 네트워크를 먼저 확인해야 합니다.

개인키나 거래 정보는 어디로 전송되나요?

거래 서명은 기기에서 수행하며 개인키 자체를 조회 서버로 전송하지 않도록 설계했습니다. 잔액·UTXO 조회와 거래 전송에는 외부 네트워크 서비스가 사용되므로 주소 관련 조회 정보와 접속 IP 등은 해당 서비스에 전달될 수 있습니다. 자세한 내용은 개인정보처리방침을 확인하세요.

앱과 이 웹페이지에 로그인이 필요한가요?

별도의 서비스 계정 가입 없이 이용합니다. 앱의 PIN은 로그인 비밀번호가 아니라 지갑을 보호하는 잠금장치입니다. 전송 작업 중 다른 앱이나 홈 화면으로 이동하면 화면을 잠그고, 돌아왔을 때 다시 인증하도록 해 다른 사람이 지갑을 사용하는 것을 막아줍니다. 이 소개 페이지에는 지갑 연결, 개인키 입력, 결제, 분석용 스크립트를 넣지 않았습니다.

소스코드를 확인하거나 개선에 참여할 수 있나요?

네. 앱 소스는 GitHub에 MIT 라이선스로 공개되어 있습니다. 오류 제보와 개선 제안은 GitHub Issues로 남겨 주세요. 개인키, 복구 문구나 개인정보는 올리지 마세요.
